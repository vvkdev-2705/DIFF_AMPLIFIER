# CMOS Differential Amplifier Design

Cadence Virtuoso design files and GDS layout for a CMOS differential amplifier.

## Repository Structure
* `Differential_Amp/`: Cadence library containing schematics and layouts
* `diff_amp_layout.gds`: Exported layout file
* `cds.lib`: Cadence library setup file
* `drc.sum` & `lvs.sum`: DRC and LVS verification summaries
